# Vendored Cursor `agent.v1` schema

`agent_pb.ts` is a generated Connect/protobuf TypeScript schema for Cursor's
unofficial `agent.v1` wire. This copy comes from the MIT-licensed community
catalogs used by https://github.com/can1357/oh-my-pi and originally published
for https://github.com/Rahularya01/pi-cursor (copyright 2026 Rahul Arya).
DeepSeek Harness vendors the generated TypeScript so this adapter can speak
that wire without a runtime dependency on those packages.

The Cursor integration is unofficial. Cursor may change auth URLs, headers, or
the proto without notice.
